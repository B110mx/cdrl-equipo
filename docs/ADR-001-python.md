# ADR-001 - Elección de Python
El equipo decidió utilizar Python porque este lenguaje ofrece un control más eficiente y flexible en el desarrollo ya que su sintaxis sencilla facilita la creación y mantenimiento del código

los motivos por el cual escoguimos este lenguje es que tiene un ecosistema muy completo de librerías y frameworks, es multiplataforma y versátil, lo que permite que funcione en diferentes sistemas operativos sin complicaciones y destaca por su integración sencilla con bases de datos y APIs, lo que hace más rápido y práctico conectar aplicaciones con otros sistemas o manejar información.

estaremos utilizará Python 3 para validar el contrato y ejecutar las pruebas automáticas
